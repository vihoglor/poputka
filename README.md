# Отчет по Лабораторной работе № 1

**Проект:** Веб-приложение для поиска попутчиков.

##  Чек-лист соответствия требованиям методички

### 1. Содержание страницы (Выполнено на 100%)
*   **Шапка (Header):** Присутствует название проекта («БЛАБЛАКАР») и  навигация `nav` («Поиск», «Предложить поездку», «Личный кабинет»).
*   **Главный заголовок:** Размещен тег `h2` с кратким объяснением решаемой задачи.
*   **Коллекция карточек:** Реализован блок из **8 карточек** популярных маршрутов. У каждой карточки выведены название направления (Уфа → Город).
*   **Визуальное представление:** Карточки снабжены интерактивными состояниями, в Hero-блоке присутствует тематическое изображение.
*   **Форма поиска/фильтрации:** Содержит **4 поля разных типов** (`text` для городов, `date` для календаря, `number` для пассажиров) и кнопку отправки «Найти».
*   **Подвал (Footer):** Содержит многоколоночную структуру с маршрутами и контактами.

---

## Техническая реализация и структура кода

### HTML-разметка
*   Документ имеет валидный каркас: объявлен `<!doctype html>`, кодировка UTF-8 и метатег viewport для мобильных устройств.
*   Соблюдена строгая семантика тегов: `header`, `nav`, `main`, `article` (для карточек маршрутов) и `footer`.
*   Все поля формы связаны со своими текстовыми подписями через связку атрибутов `id` и `for`.

### CSS-оформление и сетки
*   **Методология сеток:** 
    *   **CSS Grid** применен для многомерных структур: сетка карточек (`grid-template-columns: repeat(auto-fit, minmax(280px, 1fr))`), форма поиска и структура подвала.
    *   **Flexbox** применен для одномерных элементов: навигационное меню в шапке и флекс-блоки внутри карточек.
*   **Адаптивность (Mobile First):** Страница проверена на контрольных точках (360px, 768px, 1280px). Горизонтальная прокрутка отсутствует. При уменьшении экрана карточки маршрутов и форма поиска автоматически перестраиваются в одну колонку.
*   **Интерфейс:** Выдержана единая цветовая палитра (основной бирюзовый `#41a5c0`, темные подложки `#4c5571` и `#393939`). Все интерактивные элементы имеют плавные переходы (`transition`) и сохраняют рамки фокуса для доступности.
