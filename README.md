# Отчет по Лабораторной работе № 1

**Проект:** Веб-приложение для поиска попутчиков.


Что сделано
*   **Шапка (Header):** Присутствует название проекта («БЛАБЛАКАР») и  навигация `nav` («Поиск», «Предложить поездку», «Личный кабинет»).
  <img width="1436" height="65" alt="image" src="https://github.com/user-attachments/assets/27a5b8eb-b7ff-4ece-86dc-45553740b0a9" />

*   **Главный заголовок:** Размещен тег `h2` с кратким объяснением решаемой задачи.
*  **Визуальное представление:** Карточки снабжены интерактивными состояниями, в Hero-блоке присутствует тематическое изображение.
  <img width="1420" height="449" alt="image" src="https://github.com/user-attachments/assets/3a7ad244-45d1-41df-80b7-32456d9828cf" />

*   **Коллекция карточек:** Реализован блок из **8 карточек** популярных маршрутов. У каждой карточки выведены название направления (Уфа → Город).
  <img width="1382" height="257" alt="image" src="https://github.com/user-attachments/assets/d0cee6e6-b58b-4c16-866f-7ddac5b484bf" />


*   **Форма поиска/фильтрации:** Содержит **4 поля разных типов** (`text` для городов, `date` для календаря, `number` для пассажиров) и кнопку отправки «Найти».
  <img width="1409" height="111" alt="image" src="https://github.com/user-attachments/assets/a2a216b0-d25b-4b51-b40b-fb39c1ac2be4" />

*   **Подвал (Footer):** Содержит многоколоночную структуру с маршрутами и контактами.
